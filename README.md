# MyProxyApp — Android Proxy Client

Готовый проект приложения для подключения к HTTP/HTTPS прокси с авторизацией (логин и пароль).

## Как получить готовый `.apk` файл без установки Android Studio (через GitHub):
1. Создайте новый репозиторий на [GitHub](https://github.com/new).
2. Распакуйте этот архив и загрузите все файлы в репозиторий (включая папку `.github`).
3. Перейдите во вкладку **Actions** в вашем репозитории — сборка запустится автоматически.
4. Через 1–2 минуты откройте завершённый процесс сборки и скачайте готовый файл **`MyProxyApp-debug-apk`** в разделе **Artifacts**.
